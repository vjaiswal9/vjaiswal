# Bliss Crafted

Premium event management platform prototype.

## Local development

Requirements: Node.js 20+ and npm.

```bash
cd bliss-crafted
npm install
npm run dev
```

Open http://localhost:3000

## Current milestone

The prototype includes:
- Next.js + TypeScript app foundation
- Premium responsive homepage
- Event services
- Portfolio / experiences
- Interactive quick event planner with dummy pricing
- Centralized dummy data in `lib/data.ts`

## Dummy data

All event names, prices, contact details, testimonials and imagery are placeholders. Replace them later without changing the overall UI architecture.
